一、C# 基础常用关键字释义
================================================================================

  关键字      作用                                    工控场景举例
  ───────     ─────────────────────────────────────   ─────────────────────
  class       定义类 = 功能模板 / 图纸                  ModbusProtocol 类
  public      公开权限，所有代码都能调用                 公开方法给外部调用
  private     私有权限，只能在当前类内部使用             隐藏内部变量 _client
  readonly    只读修饰符，赋值后永远不能修改             固定通信对象防手滑
  new         创建实例 = 把模板变成实际能用的对象         new ModbusSerialClient(...)
  void        方法执行完不返回任何数据                   只执行动作不返回值
  ushort      无符号短整型，工控寄存器专用               存放位置、地址、数值
  byte        字节类型                                  存设备地址、报文
  bool        布尔类型，true(开) / false(关)             开关量、限位状态
  return      把方法内部结果返回给调用处                 返回读取到的数值
  构造函数    和类名同名，创建对象时自动执行             传参数、初始化配置
  变量        存放数据 / 存放对象的容器                  只是容器名，不是实际功能

  极简速记：
      class 是图纸，new 是照着图纸盖房子
      public 是大门（谁都能进），private 是卧室（只有自己能进）
      readonly 是"结婚证"（绑定了就不能改）
      ushort 存数字，bool 存开关，void 只干活不交作业

二、async / await / Task 异步操作
================================================================================

  核心作用：读写串口、读取设备数据时不会卡死软件界面

  通俗理解：
      同步执行：就像打电话等对方回复，这期间啥也干不了
      异步执行：就像微信发消息，发完后可以继续做别的事
               设备回复后系统自动回来处理数据

  适用场景：工控上位机几乎所有读写数据的方法都会用到

  固定写法模板：
      public async Task<ushort> ReadRegisterAsync(byte slaveId, ushort address)
      {
          var result = await _client.ReadHoldingRegistersAsync(...);
          return result;
      }

      ┌─────────────────────────────────────────────┐
      │  async = 开启异步（标记这个方法可以异步执行） │
      │  await = 等待数据（在此处等待但不卡界面）    │
      │  Task  = 表示这个任务正在后台运行             │
      └─────────────────────────────────────────────┘

  新手口诀：
      看见 async → 这个方法可以异步
      看见 await → 在这里等但不卡界面
      异步语法只管记：async 开启，await 等待，全程保证界面不卡顿

三、event 事件机制
================================================================================

  核心作用：完成消息通知，一件事情做完后主动告知其他模块

  通俗理解：
      同步方式：不停问"数据好了吗？好了吗？" → 浪费资源
      事件方式：数据好了主动通知你 → 高效自动

  工控场景：
      数据读取完成 → 主动通知 UI 更新显示
      设备状态改变 → 主动通知管理层做判断

  示例：
      public event Action<float> PositionUpdated;
      // 代表位置/数值发生变动，主动推送更新通知

  新手口诀：
      event 事件只记：完成任务主动发通知，自动刷新界面数据

四、常量 const 用法
================================================================================

  作用：定义固定不变的地址编号
  好处：不用记枯燥的数字，用英文名字代替，代码好读、不易出错

  固定写法：
      // 位置类寄存器地址
      public const ushort ADDR_CURRENT_POSITION = 1009;

      // 控制寄存器地址
      public const ushort ADDR_CONTROL          = 1010;

      // 线圈地址
      public const ushort ADDR_COIL_MANUAL_FORWARD = 104;

      // 限位输入地址
      public const ushort ADDR_DI_POS_LIMIT     = 2;

  使用规则：
      命名：全大写 + 下划线（如 ADDR_CURRENT_POSITION）
      类型：ushort（寄存器专用类型）
      const 修饰的变量：定义后任何地方都不能修改其值

五、数字命令 与 true/false 的本质区别 ★ 重点
================================================================================

  ┌───────────────────┬────────────────────────────────────────┐
  │     数字命令      │              true / false              │
  ├───────────────────┼────────────────────────────────────────┤
  │ 用于 WriteRegister │ 用于 WriteCoil 线圈、ReadDI 限位      │
  │ 写寄存器方法       │ 代表电路通断、开关状态                │
  │                   │                                        │
  │ 设备厂家规定的命令  │ 程序逻辑判断用语                       │
  │ 1=启动 2=停止     │ true=接通 false=断开                  │
  │ 3=调速 4=模式切换 │                                        │
  │                   │                                        │
  │ 设备只认识数字     │ 设备不直接识别 true/false             │
  └───────────────────┴────────────────────────────────────────┘

  ★ 绝对不能混用！
     写启动命令 → 传数字（WriteRegister）
     控制点动   → 传 true/false（WriteCoil）

六、新手识代码万能口诀
================================================================================

  代码参数出现 high、low 两段参数
      一律是拆分 / 拼接设备寄存器数据

  方法名带 ToInt32
      拼接整数

  方法名带 ToFloat
      拼接小数

  方法名带 ToRegisters
      拆分数据

  代码出现 <<
      代表数据拼接（左移合并）

  代码出现 >>
      代表数据拆分（右移分离）

  ToHexString
      专属串口调试看报文

  ToInt16
      专属读取设备负数数据

  异步语法只管记：
      async 开启异步，await 等待数据，全程保证软件界面不卡顿

  event 事件只记：
      完成任务主动发通知，自动刷新界面数据

七、关键词极简释义汇总（速查表）
================================================================================

  关键词              含义
  ──────────          ───────────────────────────────────────
  ModbusProtocol      自定义 Modbus 功能工具类（拼装指令）
  ModbusSerialClient  现成串口通信类（负责收发数据）
  _client             类内部存放通信对象的私有变量
  ReadRegister        读数值寄存器方法
  WriteRegister       写数字命令寄存器方法
  WriteCoil           写开关线圈方法
  ReadDI              读只读限位开关方法
  slaveId             设备站号 = 设备地址
  address             寄存器 / 线圈 / 限位地址
  const               定义固定不变地址常量
  构造函数            创建对象时自动传参绑定
  线圈 Coil           可读写控制开关
  离散输入 DI         只读外部传感器开关
  ushort              寄存器专用数值类型
  bool                开关状态专用类型
  CRC 校验            Modbus 通信固定校验规则，保证数据无误
  async / await       异步操作，不卡界面
  event               事件通知机制
