================================================================================
二、两大核心对象详解
================================================================================

1. ModbusSerialClient（串口通信工具）
─────────────────────────────────────
  身份：现成的第三方串口通信工具类（别人写好的"轮子"）

  作用：只负责三件事
       ① 打开串口
       ② 发送 Modbus 报文
       ③ 接收设备回复数据

  创建格式：
       ModbusSerialClient 通信兵 = new ModbusSerialClient("COM3", 9600);

  参数说明：
       "COM3" ：电脑的串口号（设备管理器中查看）
       9600   ：通信波特率，设备和代码必须完全一致

  使用规则：只有 new 新建对象时，才能在后面加括号传配置参数
            单纯声明变量不能加括号

  ┌──────────────────────────────────────────────────────┐
  │  ModbusSerialClient 通信兵 = new ...   ← 正确写法   │
  │  ModbusSerialClient 通信兵;            ← 声明变量   │
  │  通信兵 = new ModbusSerialClient("COM3", 9600);     │
  └──────────────────────────────────────────────────────┘


2. ModbusProtocol（自定义 Modbus 工具类）
─────────────────────────────────────
  身份：我们自己手写的 Modbus 功能工具类（"文书"）

  核心职责：
       不负责串口的打开 / 关闭
       只负责拼装标准 Modbus 指令、计算 CRC 校验
       调用传入的通信对象完成数据收发

  内部结构：
       private readonly ModbusSerialClient _client;
       // 私有容器，存放通信对象

       public ModbusProtocol(ModbusSerialClient client)
       {
           _client = client;  // 构造函数完成绑定
       }

       内置固定方法：
           ReadRegister   读寄存器
           WriteRegister  写寄存器
           WriteCoil      写线圈
           ReadDI         读离散输入（限位开关）


3. _client（私有容器变量）
─────────────────────
  身份：类内部定义的私有容器变量

  作用：专门用来存放外面传进来的 ModbusSerialClient 通信对象

  核心关系：
       ModbusSerialClient = 类型（是什么东西）
       _client            = 变量名（给这个东西起的内部名字）

  赋值方式：只能通过构造函数把外部通信对象传入赋值
            不能直接写端口参数


================================================================================
三、对象绑定完整流程（核心串联逻辑）
================================================================================

  ┌──────────────┐      ┌──────────────────┐      ┌─────────────────┐
  │   new 通信兵  │ ──→  │  new 文书(通信兵) │ ──→  │  内部 _client   │
  │  ("COM3",9600)│      │                  │      │   = 通信兵      │
  └──────────────┘      └──────────────────┘      └─────────────────┘
      第一步                                   第二步                                              第三步

  详细步骤：

  第一步：外部新建带端口、波特率的真实通信对象
      ModbusSerialClient 通信兵 = new ModbusSerialClient("COM3", 9600);

  第二步：新建我们自己的功能类 ModbusProtocol，把通信兵传进去
      ModbusProtocol 文书 = new ModbusProtocol(通信兵);

  第三步：类内部构造函数完成赋值绑定
      public ModbusProtocol(ModbusSerialClient client)
      {
          _client = client;  // 绑定完成！
      }

  绑定完成后：
       内部 _client 就等于外部建好的通信兵
       可以直接调用通信功能（收发数据）

四、四大固定工控读写方法
================================================================================

  以下四个方法是行业标准 Modbus 协议，代码一辈子固定不变
  项目直接复制粘贴，无需修改一行！
  CRC 校验算法：固定公式，直接自带使用，不用理解原理

  ┌─────────────────────────────────────────────────────────────────────┐
  │  方法名         用途                 返回值       调用格式          │
  ├─────────────────────────────────────────────────────────────────────┤
  │ ReadRegister   读寄存器数值          ushort       文书.ReadRegister │
  │                                              (设备地址, 寄存器地址) │
  │                                                                     │
  │ WriteRegister  写数值命令（数字）    void         文书.WriteRegister │
  │                                              (设备地址, 寄存器地址, │
  │                                               写入数字)             │
  │                                                                     │
  │ WriteCoil      写开关量（true/false） void        文书.WriteCoil    │
  │                                              (设备地址, 线圈地址,   │
  │                                               布尔状态)             │
  │                                                                     │
  │ ReadDI         读离散输入（只读开关） bool         文书.ReadDI      │
  │                                              (设备地址, 限位地址)   │
  └─────────────────────────────────────────────────────────────────────┘


  1. ReadRegister 读寄存器
     固定用途：读取设备里存放数字的寄存器数据
     可读内容：电机当前位置、目标位置、电压、电流、温度、转速
     调用格式：文书.ReadRegister(设备地址, 寄存器地址);
     实例：
         ushort 现在位置 = 文书.ReadRegister(1, 1009);

  2. WriteRegister 写寄存器
     固定用途：往设备寄存器写入数字命令
     常用场景：设置目标位置、写入运行参数、设备启停数字指令
     调用格式：文书.WriteRegister(设备地址, 寄存器地址, 写入数字);
     规则：设备只认数字，不认 true/false
           1 = 启动、2 = 停止，都是厂家设备手册规定死的
     实例：
         文书.WriteRegister(1, 1010, 1);  // 1号设备 1010地址 写入1=启动

  3. WriteCoil 写线圈
     用途：控制设备开关量动作（点动、正转、反转、电磁阀开关）
     传参只能用：true / false
         true  = 接通、开启、点动运行
         false = 断开、关闭、停止点动
     调用格式：文书.WriteCoil(设备地址, 线圈地址, 布尔状态);
     实例：
         文书.WriteCoil(1, 104, true);  // 1号设备104线圈 正向点动开启

  4. ReadDI 读离散输入（只读开关）
     用途：读取外部传感器、限位开关状态
     特点：只能读、不能写
     返回值：bool
         true  = 触发、到位、碰到限位
         false = 未触发、远离限位
     实例：
         bool 碰到正限位 = 文书.ReadDI(1, 2);

五、三个地址彻底分清（最易混淆知识点！）
================================================================================

  ┌────────────────┬──────────────────┬───────────────────────────────┐
  │   地址类型     │     作用          │          说明                │
  ├────────────────┼──────────────────┼───────────────────────────────┤
  │ 设备地址/站号   │ 设备身份编号      │ 出厂默认 = 1                 │
  │ (slaveId)      │                  │ 多台设备需拨码开关手动修改     │
  │                │                  │ 是硬件编号，代码不能自定义     │
  │                │                  │ 所有读写方法的第1个参数         │
  ├────────────────┼──────────────────┼───────────────────────────────┤
  │ 寄存器地址      │ 存放数值的位置    │ 存位置、温度、电压等          │
  │ (address)      │                  │ 用 const 常量固定写死         │
  ├────────────────┼──────────────────┼───────────────────────────────┤
  │ 线圈/限位地址   │ 控制动作开关      │ 线圈地址：控制动作开关        │
  │                │ / 传感器输入      │ 离散输入地址：读取限位传感器   │
  │                │                  │ 按照设备手册填写，固定不变     │
  └────────────────┴──────────────────┴───────────────────────────────┘

  特别注意：
      设备地址不属于代码自定义，是设备的硬件身份编号
      代码里的数字必须和设备内部设置完全一致，否则无法通信！
      所有读写方法的第一个参数，全都是设备地址


================================================================================
六、方法代码通用规则
================================================================================

  ReadRegister、WriteRegister、WriteCoil、ReadDI
     内部实现代码全部是行业标准 Modbus 协议
     一辈子固定不变，项目直接复制粘贴，无需修改一行
     CRC 校验算法：固定公式，直接自带使用，不用理解原理

  所有方法只需要修改三处内容：
      ① 设备地址（1、2、3…）
      ② 寄存器 / 线圈 / 限位地址
      ③ 写入的命令数字或布尔状态


================================================================================
七、执行逻辑总口诀（背诵）
================================================================================

  新建通信兵，填好串口与波特率
  传入自定义 Modbus 文书类完成绑定
  常量固定所有设备内部地址
  读数值用 ReadRegister
  写运行命令用 WriteRegister 传数字
  控制点动开关用 WriteCoil 传 true/false
  读取限位传感器用 ReadDI
  第一个数字永远填写设备本身设定好的站号
